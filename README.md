IS_601 MidTerm Project

The goal of this assignment is to create a Python file that is able to read orders containing customer and order information from from a JSON file and from that information, create two JSON files with the  data and present them in an organized fashion according to Python guidelines.

My program parses the JSON file and reads the information inside and loads the information. It uses different functions to process the output and present it as required by the assignment.

You need to run the project by using the json file of orders that you will be using for input and run midterm.py (For an exact command python3 midterm.py example_orders.json) or what test file you will be using.
